# Hackathon

시민 신고를 관련 기관에 자동 배정하고, 대응 현황을 실시간으로 공유하는 긴급 사건 대응 플랫폼입니다.

## Structure

- `frontend/` — 시민·기관·관리자 화면
- `backend/` — API, DB, Routing, Timeline, WebSocket
- `infra/` — Terraform, Nginx, 배포 설정
- `docs/` — API와 WebSocket 계약
- `scripts/` — Demo Reset 등 공통 운영 명령
